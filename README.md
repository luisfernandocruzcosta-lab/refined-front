# Aura UI

Atue como um Designer de Interface (UI) e Engenheiro de Front-End de nível internacional, especializado em design minimalista premium (estilo Apple, Linear, Vercel e Stripe). 

Quero transformar o front-end atual da minha aplicação para torná-lo minimalista, sofisticado e esteticamente lindo.

Diretrizes de Design a aplicar:

1. Minimalismo e Espaçamento: Use bastante espaço em branco (whitespace) para deixar o layout respirar. Reduza bordas pesadas e divisórias desnecessárias. Use sombras muito sutis (soft shadows) e cantos arredondados elegantes (borda md a xl do Tailwind).

2. Tipografia e Hierarquia: Garanta uma hierarquia visual impecável com fontes limpas (como Inter ou Geist). Títulos elegantes, textos de apoio legíveis com cores suaves (zinc-500 / slate-500) e contraste perfeito para leitura.

3. Paleta de Cores Sofisticada: Use uma base neutra e limpa (tons de branco, cinzas ultra-claros ou modo escuro profundo estilo 'pitch black') e escolha apenas UMA cor de destaque sutil para botões principais e elementos ativos, que combine com a minha logo.

4. Componentes Premium: Implemente elementos de interface modernos usando shadcn/ui (botões com feedbacks táteis, inputs minimalistas, dropdowns elegantes com efeito blur/glassmorphism de fundo).

5. Micro-interações: Adicione transições suaves (ease-in-out com duração leve) para todos os estados de hover, active e focus. O app deve passar a sensação de ser fluido e nativo.
